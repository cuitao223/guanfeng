# 真实三维风场

更新日期：2026-11-12。

## 使用

登录气象监测平台后，顶栏点击“三维风场”，路径 `/operations/wind`。旧 `/wind-3d` 也转到该页面。原“三维态势”保留为公开站点视图，二者同时可用。

默认显示四层真实风速切片与流动粒子。左侧可以按925、850、700、500 hPa选择层，打开风羽，调整透明度、垂直放大和俯视角，切换卫星/道路底图与平滑/分级填色；底部选择时次或播放。点击地图，右侧展示最近真实模式格点的位势高度、风速和来向；展开资料说明可导出当前时次完整u/v格点数据。

## 数据来源和范围

使用NOAA/NCEP GFS 0.25°公开GRIB2数据，实际下载源为NOMADS官方筛选服务：`https://nomads.ncep.noaa.gov/cgi-bin/filter_gfs_0p25.pl`。完整带参数下载地址、SHA256和字节数见 `data/public/gfs-wind/manifest.json`，三个原始GRIB2也保存在同目录。

- 起报：2026-11-11 12:00 UTC，即北京时间20:00。
- 三时次：f000、f003、f006；有效时间分别为北京时间2026-11-11 20:00、23:00和2026-11-12 02:00。
- 区域：112°–120°E、28°–36°N，长江中下游及周边。
- 每层33×33格点，4个气压层、3个时次，共13,068组真实u/v向量。
- 三变量：UGRD、VGRD（m/s）、HGT（位势米gpm）。

这是真实公开数值模式资料：f000是模式分析时刻，f003/f006是预报；不等于雷达实测，不是实时滚动更新。页面明确展示该区别。不用站点观测插值冒充三维风场。

## 实现与科学边界

`python scripts/prepare_gfs_wind.py` 下载限定区域与变量，使用ecCodes解码；加 `--offline` 可仅从已保存GRIB重新标准化。旧周期退出NOAA滚动存档后，应使用本地原始文件复现或显式选择仍可用周期，不能自动生成替代值。

按照经纬度将原始南北扫描整理为北到南、西到东的网格。风速为 `sqrt(u*u+v*v)`，气象来向为 `(atan2(-u,-v)*180/pi+360)%360`；源u/v和每格高度完整保留。前端不解析科学文件，仅接收标准化JSON。

Three.js图层复用Harness。风速映射0–30m/s色标，各气压面以该面的平均位势高度铺成平面，因此不是逐格起伏等压面，也不是离地高度体。右侧显示所选格点真实位势高度。垂直放大×35用于看清层次，不改变导出值。

原始坐标WGS84保留。前端逐格计算GCJ02显示坐标，风羽使用对应格点坐标，切片与粒子面使用转换后的角点；四角平面投影是区域可视化近似，不作为测绘精度声明。新增可选 `pointGrid` 使格点边界以 `(nx-1)*dx` 计算，不改变旧色斑网格约定。

粒子以源u与-v（屏幕行向南）推进，方向来自原始数据；动画步长和时间播放均为演示速度，不用于推断物理传播时间。
