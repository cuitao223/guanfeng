# Harness、组件与 Skill

## 结构与调用

- `.harness/frontend/`：Vue 开发规则、页面参考、图表和地图组件。
- `.harness/backend/`：后端接口约定、Java 雷达解析参考实现、开发与生成 Skill。
- `.harness/data/`：雷达测量文件到图表字段的适配说明。
- `frontend/src/components/`：平台实际使用的可视化组件。
- `backend/src/main/java/com/leice/radar/demo/workbench/`：组件注册、数据分析、工作流执行及项目协作。
- `backend/src/main/java/com/leice/radar/demo/generation/`：模型调用、任务编排、源码校验、修复、部署与导出。

## 从需求到应用

生成任务读取 `.harness/backend/skills/guanfeng-generate/SKILL.md`，并记录加载用途与内容哈希。规划角色输出应用和工作流结构，源码角色并行生成界面与 API 模块，组装角色整合为可构建项目。随后执行受限源码检查、实际构建、工作流检查和浏览器门禁；校验失败进入有限次数的自动修正。

产品自身的 Agent 角色与开发时使用的 AI 编码助手相互独立。生成结果是实际源文件，部署启动应用进程，导出提供源码工程。

## 组件编排与数据流

工作流以节点、参数和连线描述 DAG。后端解析连接关系、检查输入输出、按依赖执行；节点状态和结果返回工作台。参数修改会重新进入数据分析链路，而非替换页面上的固定数值。

可信插件通过描述文件注册，支持版本与启停、重新加载和引用检查。项目编辑会话、版本和变更用于多人协作；本地示例登录不等于完整生产租户隔离。

## 扩展一个组件

1. 先定义输入、输出和参数契约。
2. 按现有注册方式加入处理器或可信插件描述。
3. 需要展示时复用现有图表与地图组件。
4. 更新对应 Skill 文档，并验证真实输入到输出的调用链。

运行日志、任务源码与协作数据保存在 `runtime/`，默认不进入 Git。
