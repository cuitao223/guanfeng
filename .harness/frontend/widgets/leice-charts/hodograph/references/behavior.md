# 与旧实现的差异

本包保留这些行为：

- 0 度朝北，顺时针为来向，半径为风速。
- 轨迹从圆心连到各层，层上有圆点。
- 方位标注为 N、E、S、W。
- 提示框高度使用 km。悬停距离超过 14 像素不显示提示。
- 高度缺测的层仍绘制，高度文字为「--」。负风速不画。

有意改变的行为：

- 旧缺测只把空值和 999 视为无效。本组件同时跳过小于等于 -999，因此 -1000 也不画。
- 没有任何可画层时显示「无数据」，不从圆心画出零速度轨迹。
- 极坐标网格仍然绘制。
- 不读取本地存储，不请求数据。

`dark` 对应旧主题 `default`，`light` 对应旧主题 `white`。轨迹红线沿用源图，未作为设计令牌锁定。
