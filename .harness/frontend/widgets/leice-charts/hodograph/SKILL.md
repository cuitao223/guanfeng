# 霍多图

适用于一组高度层的风矢量。每层使用 `heightKm`、`windSpeed`、`windDir`。半径是风速，0 度朝北，顺时针为来向。轨迹从圆心连到各层。组件不请求文件或设备接口。

目标运行环境是 Vue 3。绘图引擎是 D3。Node 16 及以上可以完成本包的安装、类型检查、构建和测试。

## 业务规则

- 风速或风向为 `999`、小于等于 `-999`、空串、`null`、非有限数时，该层不画。`-1000` 同样跳过。
- 风速小于 0 的层不画。风速 `0` 留在圆心附近，是有效静风。
- 高度缺测时仍画该层的风，提示里的高度显示为「--」。高度单位是 km，本图不换算成 m。
- 没有任何可画层时显示「无数据」，不画从圆心出发的零线。
- 极坐标圈和方位线在无数据时仍然保留。
- `theme` 使用 `dark` 或 `light`。轨迹色沿用源图的红线，不是已锁定的设计令牌。
