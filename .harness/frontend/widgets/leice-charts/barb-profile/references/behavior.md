# 与旧实现的差异

本包保留这些行为：

- 纵轴标题为「高度(m)」，刻度朝内，绘图区中央有一条参考线。
- 风羽几何为杆长 20、羽长 10、间距 4。
- 屏幕间距小于 26 像素的风羽被抽掉。
- 提示框显示高度 m、风速 m/s、风向度。

有意改变的行为：

- 旧实现在没有 `dirArr` 时把风向当成 0。本组件要求三个数组对齐，风向缺测则跳过该层。
- 缺测判断改为 999、小于等于 -999、空串、null 和非有限数。风速 0 保留。
- 全部不可画时显示「无数据」。
- 未传入 `color` 时，暗色用白色，亮色用深色，避免白杆落在白底上。
- 不读取本地存储，不请求数据。

`dark` 对应旧主题 `default`，`light` 对应旧主题 `white`。色值未作为设计令牌锁定。
