# 与旧实现的差异

三张总通量图合在本包里：

- 垂直通量，字段 `totalVerticalFlux`，色标 -200 到 200。
- 东向通量，字段 `totalEastFlux`，色标 -500 到 500。
- 北向通量，字段 `totalNorthFlux`，色标 -500 到 500。

本包保留这些行为：

- 时间小于 `1e12` 时按秒换成毫秒。
- 源图正在使用的换算：原始值按质量，显示摩尔时除以 44.01。源图注释里的另一套换算：原始值按摩尔，显示质量时乘以 44.01。本包用 `inputUnit` 选择其中一套。
- 柱子用时间分箱，间距比例 0.2，从零线向正负方向伸出。
- 纵轴取有效值绝对值的 1.1 倍，再取整齐刻度，正负对称。
- 默认颜色是 11 色线性渐变，断点与源图相同。切换单位不重算色标。
- 双击色标打开配置，可改渐变或等值线、右侧或底部、刻度侧、间距、透明度和断点，也可均分断档或恢复出厂。

有意改变的行为：

- 三张图合成一个组件，用 `direction` 区分，页面传入已经对齐的 `values`。
- 通量 999 和小于等于 -999 不画。源图对缺测做 `parseFloat` 后仍可能进入序列。
- 没有任何有效柱时显示「无数据」。
- 色标配置是图内对话框，不依赖外部组件库。不缩放，不导出图片，不请求接口，不读取设备编号。
