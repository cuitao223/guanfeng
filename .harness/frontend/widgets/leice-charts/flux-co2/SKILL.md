# 二氧化碳通量色柱

适用于总垂直通量、总东西通量和总南北通量。柱子从零线向上或向下伸出，颜色按发散色标渐变。组件不请求文件或设备接口。

目标运行环境是 Vue 3。绘图引擎是 D3。Node 16 及以上可以完成本包的安装、类型检查、构建和测试。

## 业务规则

- 通量为 `999`、小于等于 `-999`、空串、`null`、非有限数时，该柱不画。
- 通量 `0` 是有效值，画在零线上。
- 图上可在 `μg m-2 s-1` 与 `μmol m-2 s-1` 之间切换。`inputUnit` 说明原始值的单位，默认 `mass`。原始值是质量时，显示摩尔除以 44.01。原始值是摩尔时，显示质量乘以 44.01。单位相同则原样使用。
- 出厂色标在 `direction` 为 `vertical` 时是 -200 到 200，为 `east` 或 `north` 时是 -500 到 500。双击色标可改渐变或等值线、位置、刻度、透明度和断点。切换单位不改色标断点。
- 纵轴按有效值的绝对值对称展开，并留出一成余量。
- 没有任何有效柱时显示「无数据」。
