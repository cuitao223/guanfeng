# 来源与差异

扇区几何来自无锡平台 `RHIChart.vue`：距离门用相邻中点做半径边界，角度用圆周最短弧的中点做扇区边界。0° 在 RHI 中位于正左方。

PPI 不使用无锡平台叠在地图上的三维网格。地图图层不放进绘图组件。PPI 使用同一套扇区填色，0° 在正上方，顺时针到 90° 向右。

色标条、填色方式、位置、刻度侧、间距、透明度和恢复出厂对齐时高图。色标插值规则与时高图相同。距离环的米制刻度写在对应圆环内侧靠下的位置，不放到圆外。鼠标只有落在已填色的扇区里才显示提示，缺测格、扇区外和圆外都不弹出。

与旧页面的差别：

- 旧 RHI 会把信噪比和谱强在图内换成 dB。本组件只画传入的数值。
- 旧页面的恢复出厂色标 `[-6, -3, 0, 3, 6]` 是某一页的绘图底图色标，不写进组件默认值。
- 切变图例的无量纲分档不属于这张扫描填色图。
