# 扫描图

同一个组件画 PPI 或 RHI。`mode` 为 `ppi` 时角度是方位角，0° 在正上方，顺时针增大。`mode` 为 `rhi` 时角度是俯仰角，0° 在正左方，90° 在正上方，与无锡平台 RHI 一致。距离单位是 m。组件不请求文件或设备接口，也不绘制地图。

目标运行环境是 Vue 3。绘图引擎是 D3。色标条、色标配置和右上角按钮的形式对齐时高图。容器宽或高小于 100 时不绘制。

## 业务规则

- `999`、小于等于 `-999`、空串、`null`、`undefined`、非有限数都不画。`-1000` 同样跳过。数值 `0` 要画。
- 整段没有可画扇区时显示「无数据」，不把空序列画成 0。
- `angles` 与 `values` 按行对齐。`heightArr` 是各行共用的距离门。
- 扇区角边界取相邻角的圆周中点。整圈数据会把首尾接上。距离门边界取相邻门中点。
- 默认最大距离 15000 m。距离环在跨度不小于 9000 m 时间隔 3000 m。米制刻度写在对应圆环内侧靠下的位置，不写到圆外。
- 鼠标只有落在已填色扇区上才显示提示。缺测格、角度范围外和圆外都不显示。
- `colorMode` 为 `linear` 时平滑插值；为 `threshold` 时按等值线分档。规则与时高图相同。
- 图右侧默认带数值色标，刻度在色带外侧。双击色标打开配置。
- 右上角有框选缩放、还原、下载和距离范围设置。滚轮缩放最大 8 倍。
- `theme` 使用 `dark` 或 `light`。调用方用 `breakpoints`、`colors` 和 `palette` 覆盖。这些不是已锁定令牌。
- 信噪比、谱宽、谱强由调用方换成展示用的数值后再传入。组件不在内部做 dB 换算。
