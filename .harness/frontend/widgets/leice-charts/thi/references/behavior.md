# 来源与差异

填色保留 600 秒时间空档、整列缺测和 Unix 秒。双线性是填色的一种做法。

平滑与等值线色标分开。格式化时间使用 `YYYY-MM-DD HH:mm:ss`，解析成本地时间。

缺测判断在采样前把空串、`999` 和小于等于 `-999` 设为无效。只跳过非有限数时，空串可能被当成 0。

没有搬入 `designPx` 缩放、页面请求、工具栏和风羽层。轴色使用 default / map 预设，不作为设计令牌。

按列抽稀没有沿用。本组件改为按屏幕像素采样整段网格：线性模式对采样点做双线性，等值线模式取最近格子，不把缺测角点当成 0。位图上限是 480×320，再画到绘图区。

悬停和十字丝吸附最近时刻和高度，提示时间用本地 `YYYY-MM-DD HH:mm:ss`，有效值带色点；时间空档显示缺测和起止。缺测格不借用邻格。时间轴刻度同时写 `YYYY-MM-DD` 和 `HH:mm:ss`。绘图区上下左右都有轴线，并加一圈闭合边框。滚轮以指针为锚、倍率 1.15、最大 5 倍，拖拽平移视口；框选按钮打开后拖拽仍是矩形缩放。还原回到数据全范围。下载把画布、坐标轴和色标合成 PNG。高度设置是 Element Plus 双柄滑条，范围取数据高度，两端分别是最低和最高。色标条默认在绘图右侧，也可改到底部。右侧时默认色带靠绘图、刻度在色带右侧，间距 8px，也能改回色带左侧并调整间距。双击打开 Element Plus 色标配置。绘图区内用 4,4 虚线画出时间轴和高度轴刻度。右上角还原、下载、设置和框选套上同样的圆形底。
