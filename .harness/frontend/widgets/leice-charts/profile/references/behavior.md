# 与旧实现的差异

本包保留这些行为：

- 纵轴标题为「高度(m)」，大刻度 1000 m，小刻度 200 m，刻度朝内。
- 提示框显示高度 m 和数值。
- 默认线色 `#4EA8FF`。
- 横轴未传入时按数据留白；传入 `xDomain` 后，数据超出才扩大范围。

有意改变的行为：

- 旧 `samplePoints` 在数组为空时生成 `value` 为 0 的采样点。本组件不保留该函数。
- 旧 `buildPoints` 会丢掉缺测点，折线把两侧有效点直接连上。本组件在缺测处断开。
- 有相邻有效点连成折线时，这些点初始不画圆点，鼠标悬停才显示当前点。左右都没有相邻有效点的散点，初始就画圆点。
- 缺测判断改为 999、小于等于 -999、空串、null 和非有限数。数值 0 保留。
- 全部不可画时显示「无数据」。
- 不读取本地存储，不请求数据。

`dark` 对应旧主题 `default`，`light` 对应旧主题 `white`。色值未作为设计令牌锁定。
