# 数据契约

`pressure`、`value`、`windDir`、`height` 是平行数组。

| 字段 | 含义 |
| --- | --- |
| `pressure` | 气压，单位 hPa。小于等于 0 不画 |
| `value` | 风速，单位 m/s。小于等于 0 不画 |
| `windDir` | 来向角度。0 度朝北，顺时针增大 |
| `height` | 高度，单位 m。缺测时风羽仍可画 |
| `theme` | `dark` 或 `light` |
| `palette` | 覆盖主题里的单项颜色 |

气压、风速或风向为 999、小于等于 -999、空串、`null` 或非有限数时跳过。高度使用同一缺测规则，缺测显示为「--」。
