# 与旧实现的差异

本包保留这些行为：

- 纵轴对数气压，下界 1050 hPa，上界 200 hPa。
- 标准层为 1000、925、850、800、750、700、600、500、400、300、250、200。
- 样本画在最近标准层上，距离超过相邻层间距的一半则放弃。
- 风羽比例 1.5，杆长沿用风羽几何。
- 风速小于等于 0 不画。

有意改变的行为：

- 旧缺测只把空值、非数和 999 视为无效。本组件同时跳过小于等于 -999。
- 没有任何可画层时显示「无数据」。
- 不请求数据，不读取设备编号。

`dark` 对应旧主题 `default`，`light` 对应旧主题 `white`。
