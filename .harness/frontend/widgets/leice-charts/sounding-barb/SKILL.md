# 探空风羽

适用于探空各气压层的风速和风向。纵轴是对数气压，1000 hPa 在下，200 hPa 在上。风羽画在最近的标准气压层上。组件不请求文件或设备接口。

目标运行环境是 Vue 3。绘图引擎是 D3 与画布。Node 16 及以上可以完成本包的安装、类型检查、构建和测试。

## 业务规则

- 气压、风速或风向为 `999`、小于等于 `-999`、空串、`null`、非有限数时，该样本不画。
- 气压小于等于 0，或风速小于等于 0，不画。风速 0 在本图是静风，不是有效风羽。
- 高度缺测时仍可画风羽，提示里的高度为「--」。高度为 999 或小于等于 -999 时视为缺测。
- 样本吸附到标准层 1000、925、850、800、750、700、600、500、400、300、250、200 hPa，距离超过相邻层间距的一半则不画。
- 没有任何可画层时显示「无数据」。
- 0 度朝北，顺时针为来向。风羽比例 1.5。
