# 与旧实现的差异

本包保留这些行为：

- 同一张图可叠填色、折线和风羽。
- 时间字符串格式为 `YYYY-MM-DD HH:mm:ss`。
- 风羽几何与单时次风羽相同，来向 0 度朝上。
- 等温线保留 0、-20、-30、-40 的线色。
- 默认抽稀步长为 3，填色不透明度为 0.7。

有意改变的行为：

- 页面上的显隐开关收成 `layers`。只传入要画的层，`visible: false` 的层跳过。
- 缺测判断改为 999、小于等于 -999、空串、null 和非有限数。数值 0 保留。
- 填色按最近的时间列和高度门取色，不在缺测格上做双线性插值。
- 本版不提供滚轮缩放和拖拽。时间窗由 `timeStart` 与 `timeEnd` 决定。
- 跨度超过一天时，时间刻度带上月和日。
- 全部不可画时显示「无数据」。
- 每个带断点和颜色的可见填色层画一条色标，名称和单位取自该层。名称单独占一行，刻度留在色带高度内，避免名称和端点刻度叠在一起。
- 色标放在底部时横向排列。每条最宽 420px，条数超出可视宽度时在这一行里水平滚动。
- 双击色标打开该层的配置：填色方式、断点、颜色、透明度、刻度侧和间距。色标位置作用于全部色标。可均分断档或恢复该层的传入值。分段色带的规则与时高图色标相同。
- 不读取本地存储，不请求数据。

`dark` 对应旧主题 `default`，`light` 对应旧主题 `white`。色值未作为设计令牌锁定。
