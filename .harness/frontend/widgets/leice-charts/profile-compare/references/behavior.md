# 与旧实现的差异

本包保留这些行为：

- 纵轴标题为「高度(m)」，大刻度 1000 m，小刻度 200 m，刻度朝内。
- 提示框按当前高度列出每条仍有值的序列。
- 高度范围边界对连续有效段做线性插值。

有意改变的行为：

- 旧采样函数在数组为空时会生成值为 0 的点。本组件不保留该行为。
- 旧实现先丢掉缺测点，再按高度排序，折线会穿过缺测。本组件在缺测处断开，不跨缺测插值。
- 缺测判断改为 999、小于等于 -999、空串、null 和非有限数。数值 0 保留。
- 全部不可画时显示「无数据」。
- 本版不播放序列形态动画。
- 不读取本地存储，不请求数据。

`dark` 对应旧主题 `default`，`light` 对应旧主题 `white`。色值未作为设计令牌锁定。
