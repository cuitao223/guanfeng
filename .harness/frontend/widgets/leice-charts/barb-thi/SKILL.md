# 风羽时高图

适用于一张时间-高度风羽图。时间可以是 Unix 秒，或 `YYYY-MM-DD HH:mm:ss`。`values` 与 `dirs` 按时间行、高度列对齐。高度单位是 m。风速单位由 `unit` 显示，默认 m/s。风向是来向，单位是度。组件不请求文件或设备接口。

目标运行环境是 Vue 3。绘图引擎是 D3。时间轴、色标和右上角设置的形式对齐当前时高图。容器宽或高小于 100 时不绘制。

## 业务规则

- `999`、小于等于 `-999`、空串、`null`、`undefined`、非有限数都不画。`-1000` 同样跳过。风速 `0` 要画，只画杆。
- 风速或风向任一缺测，该格不画。不要把缺测风向画成 0°。
- 整段没有可画风羽时显示「无数据」，不把空序列画成 0。
- 0° 在正上方，顺时针增大。杆朝来向，羽在来向一端。
- 杆长 20，羽长 10，间距 4。每 20 一面旗，每 4 一笔长划，余数大于 0 再画一笔短划。杆长用风速的非负部分。
- 按屏幕间距抽稀。疏密滑条 1 到 8，默认 3，对应间距 12 到 96 像素。放大后会画出更多风羽。
- 大小滑条 2 到 20，默认 8，杆长倍率是滑条值除以 10。粗细滑条 1 到 10，默认 2，线宽是滑条值除以 2。
- 风羽颜色按风速查色标。`colorMode` 为 `linear` 时平滑插值；为 `threshold` 时按等值线分档。
- 鼠标悬停显示时间，以及带色点的高度、风速和风向。提示框样式与时高图一致。
- 右上角有框选缩放、还原缩放、图片下载和设置。缩放和平移同时改变时间和高度。
- 图右侧默认带数值色标，刻度在色带外侧。可改到底部。双击色标打开配置。
- `theme` 使用 `dark` 或 `light`。调用方用 `breakpoints`、`colors` 和 `palette` 覆盖。这些不是已锁定令牌。
