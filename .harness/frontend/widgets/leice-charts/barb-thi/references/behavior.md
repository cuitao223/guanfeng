# 来源与差异

风羽在屏幕坐标旋转，不在横纵方向上拉伸。

- 杆长 20、羽长 10、间距 4，先画旗再画长划，余数画一笔短划。
- 平移到落点后按风向角度顺时针旋转。旋转前杆从落点画到正上方。
- 时间在横轴，高度在纵轴，刻度形式与时高图相同。
- 提示为时间、高度 m、风速、风向 °。

与旧页面的差别：

- 旧时序风羽是单一笔画色，并且叠在填色层上。本组件只画风羽，颜色按调用方色标取值。
- 旧页面用固定下标步长抽稀。本组件的疏密滑条按屏幕间距调节，默认 3 对应 36 像素，1 最密，8 最疏。
- 右上角四个按钮、高度范围弹窗、色标位置、刻度侧、间距和透明度对齐时高图。
- 滚轮放大不超过初始时间和高度跨度的 5 倍。
- 默认两色色标只是没有传入色标时的回退，不是产品风色标。
