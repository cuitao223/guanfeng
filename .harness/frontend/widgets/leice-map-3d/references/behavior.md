# 与参考页的差异

来源是 GALAM-IP 的三维风页和低空气象页。下面这些地方没有原样保留。

- 粒子沿用参考页的数量、寿命 60 帧、每秒 24 帧、底图颜色和 `9999` 空洞。运动是画布上的短线，不是参考页里的 Windy 积分器。
- 风场仍把归一化风速写入纹理，再用色标查找颜色。等值线用分段色标和线性过滤，平滑用线性色标和最近过滤。
- 风羽使用普通线段。参考页使用屏幕空间等宽着色器。抽稀、尺寸和羽数规则保持一致。
- 报警面按格点等级填色，并在等级交界画线段。线段是普通线段，不是参考页的屏幕空间等宽线。水平、垂直切变读切变图，不从风速差分。
- 缩放 1 倍时，双线性插值只要四邻域里有 `9999`，当前格也记为缺测。
- 设备悬停把编号交给页面。组件不自己打开信息窗。
- PPI 使用未开启径向补洞时的分扇规则。方位间隙填补和四角门槛留在页面。
- 绘图编辑、剖面墙和实时告警连接不在本包。空间标尺由 `VolumeScaleLayer` 按风场范围绘制。
- 风场图像解码放在 `windImage.mjs`，页面传入像素。填色面片的东、南边界仍是 `lo1 + nx * dx` 和 `la1 - ny * dy`，比图像里的 `lo2`、`la2` 多出一个步长。只有一行数据时 `dy` 记为 0。
