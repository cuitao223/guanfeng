# 风场图像到上图

来源是无锡三维风页。页面自己取得图像像素后调用 `decodeWindFieldImage`。组件不请求接口，技能不写图像地址。

解码在 [windImage.mjs](../assets/logic/windImage.mjs)。填色上图仍用 [WindFieldLayer.vue](../assets/layers/WindFieldLayer.vue)。

## 图像

像素按 RGBA 读取。前两行是范围，从第三行起是格点。第三行是北侧第一行，列从西向东。

| 行 | 通道 | 内容 |
| --- | --- | --- |
| 0 | R | u 的最小、最大 |
| 0 | G | v 的最小、最大 |
| 0 | B | w 的最小、最大。填色、风羽和粒子都不使用 |
| 1 | R | 经度最小、最大 |
| 1 | G | 纬度最小、最大 |
| 2 起 | R、G | 该格的 u、v |

最小和最大写在同一行里：字符的码值依次放进像素，`255` 分隔两段，分隔之后遇到 `0` 结束。格点字节按 0 到 255 线性映射到对应通道的最小、最大。R 和 G 同时为 0 时，风速和来向都记为 `9999`。

风速是 `sqrt(u * u + v * v)`。来向是 `270 - atan2(v, u)` 的角度，再折回 0 到 360。0 度为正北，顺时针增大。

## 网格头

`la1` 取纬度最大，`la2` 取纬度最小，`lo1` 取经度最小，`lo2` 取经度最大。`nx` 等于图像宽度，`ny` 等于数据行数。

`dx = (lo2 - lo1) / (nx - 1)`，`dy = (la1 - la2) / (ny - 1)`。只有一行时 `dy` 为 0。

## 交给图层

每个高度一项：`{ height, header, speeds, dirs }`。

`WindFieldLayer` 使用 `header` 和 `speeds`。风速按色标最小、最大归一化后写入纹理红色通道，`9999` 透明。着色器按格心取样，再查色标。平面西、北边界是 `lo1`、`la1`，东、南边界是 `lo1 + nx * dx`、`la1 - ny * dy`。这比 `lo2`、`la2` 各多出一个步长，与参考页的面片一致。

`WindBarbLayer` 使用同一份 `dirs`。`WindParticleLayer` 使用同一份 `speeds`。参考页另有一份粒子缓冲，有效格写 `[u, -v]`，缺测写 `[0, 0]`；本包粒子不读那份缓冲。

## 切变图像

配套图与风场图分行方式相同，通道含义不同。页面调用 `decodeShearImage`。它只给报警面使用，不参与填色、风羽和粒子。

| 行 | 通道 | 内容 |
| --- | --- | --- |
| 0 | R | 水平切变的最小、最大 |
| 0 | G | 垂直切变的最小、最大 |
| 1 | R、G | 经度、纬度范围，读法与风场图相同 |
| 2 起 | R | 该格的水平切变 |
| 2 起 | G | 该格的垂直切变 |

R 和 G 同时为 0 时，两项都记为 `9999`。大风不读这张图，使用风场解码得到的风速。
